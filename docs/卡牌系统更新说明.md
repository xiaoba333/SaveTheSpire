# 《Save The Spire》卡牌系统更新说明

> 本文件补充当前卡牌系统落地后的玩法变化，不修改原 `README.md`。
> 详细架构见 `docs/卡牌系统设计.md`。

## 当前玩法变化

1. 每回合抽 5 张手牌，获得 3 点能量；点击卡牌即可打出。
2. 卡牌会消耗对应能量，能量不足时无法打出。
3. 打完或放弃剩余手牌后，点「结束回合」。
4. 怪物行动结束后，再回到玩家回合。
5. 怪物 HP ≤ 0 胜利，玩家 HP ≤ 0 失败。

## 当前规则数值

| 对象 | 数值 |
| --- | --- |
| 玩家生命 | 50 |
| 玩家能量 | 每回合 3 点 |
| 怪物生命 | 30 |
| 攻击牌 | 1 费，对怪物造成 6 点伤害 |
| 防御牌 | 1 费，玩家获得 5 点护盾 |
| 怪物攻击 | 对玩家造成 10 点伤害 |
| 怪物防御 | 给自己 +10 护盾 |

额外规则：

- 护盾优先抵伤，剩余伤害再扣血。
- 玩家和怪物在各自回合开始时清空未消耗护盾。
- 能量不足时不出牌：不扣费、不移牌、不执行效果。
- 普通牌打出后进入弃牌堆；带「消耗」效果的牌进入消耗堆。
- 抽牌堆为空时，弃牌堆洗回抽牌堆。

## 卡牌系统结构

```text
src/main/java/com/roguelike/dungeon/game/
  card/
    Card.java              卡牌定义
    CardInstance.java      手牌 / 牌堆中的具体卡牌实例
    CardType.java          攻击 / 技能 / 能力 / 状态 / 诅咒
    CardEffect.java        卡牌效果执行接口
    CardEffectContext.java 卡牌可调用的战斗操作
    CardLibrary.java       卡牌定义与起始牌组
  deck/
    CardPiles.java         抽牌堆 / 手牌 / 弃牌堆 / 消耗堆
  battle/
    Combat.java            战斗规则与回合循环
```
