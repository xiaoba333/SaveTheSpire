# 怪物设计案（第一层扩充）

> 范围：给第一层「地牢外围」补充怪物与编队，全部落在四层框架
> `game.enemy`（数据 → 脚本 → 意图 → 状态）内，不改动既有文件结构。
> 落地文件：`src/main/java/com/roguelike/dungeon/game/enemy/bestiary/ActOneExtraBestiary.java`。

---

## 一、现状与缺口

现有 11 只（`ActOneBestiary`）：

| 档位 | 明细 |
| --- | --- |
| 普通（5） | 蛆、亡灵、骷髅、探险者男、探险者女 |
| 精英（1） | 巨人遗骸 |
| Boss（5） | 凯洛斯的蛋 ×4 形态 + 凯洛斯 |

把现有意图表摊开看，覆盖面是 **直伤 / 叠甲 / 回血 / 加力量** 四种。
缺三类压力，也正是本批次要补的：

1. **持续掉血（中毒）**——现在护甲几乎能挡下全部威胁，「叠甲」是无脑解；
2. **高频小段伤害**——现有攻击多是单段大数值，薄甲和厚甲没有区别；
3. **污染玩家牌组**——全局只有 Boss 凯洛斯会塞「甲片」，普通/精英战没有这种压力；
4. **精英与 Boss 的多样性**：精英只有 1 只（打法唯一），Boss 只有凯洛斯（抉择点是蛋的破裂节奏）。

## 二、新增怪物（6 只）

全部只用现有意图 DSL（`Intents`）与状态（`StatusIds`），**不新增状态**。

### 2.1 普通怪

| ID | 名称 | 血量 | 初始状态 | 意图（循环） | 补的缺口 |
| --- | --- | --- | --- | --- | --- |
| `fungal_shambler` | 菌生蹒跚者 | 24 | — | 打5并给予 1 层中毒 / 防8 | **持续掉血**：中毒不看护甲，逼玩家在「叠甲硬吃」和「抢节奏速杀」之间选 |
| `plague_rat` | 疫鼠 | 14 | 蠕动 | 打3×2 / 给予玩家 1 层虚弱 | **高频小段**：两段伤害吃两次护甲判定；蠕动让开场那一刀打不痛它，要先剥皮再收割 |
| `iron_husk` | 铁壳虫 | 26 | — | 防10并给予玩家 1 层虚弱 / 打7 | **防御型小怪**：先削玩家输出再打，惩罚「不管它继续输出」的打法 |

> `plague_rat` 的设计原形是「三只疫鼠同场」，但**当前实战链路是 1v1**
> （`ScriptedMonsterAi` 的 `allMonsters()` 只返回自己、`allies()` 恒为空），
> 三只会让 `buffAlliesStrength` 一类意图静默失效。因此先落单只形态；
> 多怪物战斗支持到位后，只需把遭遇表的 spawn 列表改成 3 条，**数据本身不用动**。

### 2.2 精英怪

| ID | 名称 | 血量 | 阶段 | 意图 | 定位 |
| --- | --- | --- | --- | --- | --- |
| `mirror_wraith` | 镜像幽魂 | 60 | — | 塞 1 张「虚幻之影」 / 打7×2 / 防10 | **污染牌组**：越拖手牌质量越差，等于给战斗加了时间上限；两段攻击惩罚薄甲 |
| `stone_sentinel` | 石哨兵 | 90 | 血量 > 45 | 打8并给予 1 层易伤 / 防12并获得 3 力量 | **先守后攻** |
| | | | 血量 ≤ 45 | 打14并给予 2 层易伤 / 打9并给予 3 层中毒 / 打20 | 外壳碎裂，放弃防御、伤害暴涨 |

**与巨人遗骸的对照（刻意做成相反节奏）：**

| | 巨人遗骸（现有） | 石哨兵（新增） |
| --- | --- | --- |
| 残血前 | 无灵，打 6+易伤 / 打 12 | 打 8+易伤 / 防 12+3 力量 |
| 残血后 | 无灵消失，获得**复苏**（行动判定两次）+ 回血 10 | 不再叠甲，**伤害暴涨**（打 14+2 易伤 / 打 20） |
| 玩家该怎么打 | 攒爆发，一口气打穿，别让它回血 | 先把防御资源留好，再进残血阶段硬吃伤害 |

两只精英的应对手段不通用，精英战不会退化成同一种打法。

### 2.3 Boss（第二选项）

| ID | 名称 | 血量 | 阶段 | 意图 | 定位 |
| --- | --- | --- | --- | --- | --- |
| `bone_tyrant` | 骸骨暴君 | 150 | 初始：骨质疏松；血量 > 75 | 打10 / 打16并给予 2 层易伤 / 防15并获得 3 力量 | **资源管理型** |
| | | | 血量 ≤ 75：骨质疏松消失，获得**复苏**（行动判定两次） | 回15 / 打10×3 / 打22并给予 3 层易伤 / 防20并获得 4 力量 | |

**与凯洛斯的互补：**

- 凯洛斯考的是 **节奏抉择**——早点打蛋还是晚点打蛋，代价体现在「蜕变」层数（力量）上；
- 骸骨暴君考的是 **资源管理**——骨质疏松让它每次行动自伤 2 点、且受到伤害 +2，
  所以它**越挨打越脆**（鼓励速攻）；但打进残血后「复苏」会让它每回合行动两次，
  于是玩家必须先攒够防御/爆发再进残血阶段，否则会被双倍行动直接带走。

一层从此有 2 个 Boss 选项，两者对玩家的能力要求完全不同。

## 四、接入方式

`game/battle/MonsterCatalog`（把图鉴接到 1v1 战斗的适配层）已做三处改动：

1. 静态块增加 `ActOneExtraBestiary.init()`；
2. 普通怪随机池 `NORMAL_IDS` 从 4 项扩到 7 项（加入三只新普通怪）；
3. 新增 `randomElite(seed)` / `randomBoss(seed)`，可随机到新精英与新 Boss。

**默认路径未变**：`elite()` 仍固定返回巨人遗骸、`boss()` 仍固定返回凯洛斯蛋链，
不影响既有存档复现与 UI 的特殊处理（`MonsterAnims` 对 BOSS 节点有专门动画）。
要启用随机精英/Boss，由流程模块改一行调用即可。

## 五、验证结果

按真实类库逐回合推演 7 个回合（每只怪独立满血玩家，中途打掉一半血逼出阶段切换）：

| 检查项 | 结果 |
| --- | --- |
| 怪物注册 | 11 → **17** 只 |
| 遭遇创建 | 6 组新遭遇均可 `require(...).createMonsters()`，血量与设计一致（24/14/26/60/90/150） |
| 菌生蹒跚者 | 打5+1中毒 / 防8 正确交替，护甲 8 正确保留 |
| 疫鼠 | 打3×2（玩家掉 7 血）/ 上虚弱 正确交替，初始「蠕动」存在 |
| 铁壳虫 | 防10 后护甲=10，玩家虚弱逐次累加 x1→x4 |
| 镜像幽魂 | 塞牌 / 打7×2（玩家掉 14 血）/ 防10 正确 |
| 石哨兵 | T2「防12并获得3力量」→ 护甲 12、力量 3；T4 血量 ≤45 正确切入阶段 2（打14+2易伤 / 打9+3中毒 / 打20） |
| 骸骨暴君 | 骨质疏松每次行动自伤 2 点可见（150→148→146→144）；「防15并获得3力量」正确叠加到力量 6 |
| 编译 | 全工程 144 个 class 编译通过 |

## 六、待办

1. **立绘资源**：6 只新怪目前共用 `monster/placeholder.png` 回落图，
   需要美术补 `src/main/resources/monster/act1/{id}.png`
   （`fungal_shambler` / `plague_rat` / `iron_husk` / `mirror_wraith` / `stone_sentinel` / `bone_tyrant`）。
2. **卡牌依赖**：镜像幽魂依赖卡牌侧新增 `mirror_shade`（「虚幻之影」）。
   未实装时 `ScriptedMonsterAi` 会记一行日志并跳过塞牌，**不会崩**，但该怪会少一个机制。
3. **多怪物战斗支持**：疫鼠群、探险者二人组都需要 `BattleContext.allMonsters()/allies()`
   返回真实阵容。当前 1v1 下这两组编队只有单只生效。
4. **数值待实测**：骸骨暴君的「复苏」阶段（150 血里后 75 血要面对双倍行动）偏难；
   若过强，首选调参是把阈值从 75 下调到 50。
5. **两个 bestiary 类的归并**：`ActOneExtraBestiary` 是独立文件（避免与他人改动冲突），
   后续确认无冲突后可以并回 `ActOneBestiary`，让「第一层怪物唯一出处」这一约定重新成立。
