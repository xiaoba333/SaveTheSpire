# 卡牌设计状态

本文档记录当前卡牌定义、效果和实现状态，供后续开发与测试参考。

## 状态图例

- `已实现`：卡牌效果已经可以正常执行。
- `效果表达式已写`：卡牌效果调用链已写，但底层状态结算可能尚未完全生效。
- `未实现`：卡牌仅登记定义，效果为空或依赖尚未完成的系统。

## 稀有度映射

- 设计文档 `1` 对应 `COMMON`（普通）
- 设计文档 `2` 对应 `UNCOMMON`（罕见）
- 设计文档 `3` 对应 `RARE`（稀有）
